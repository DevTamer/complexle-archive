# Candy

**Puzzle date:** 2026-09-29  
**Category:** arrays  
**Time complexity:** `O(n)`  
**Space complexity:** `O(n)`

## Explanation

The dominant cost here comes from the two separate linear scans over the ratings list, plus the initial list creation, all of which run in a single pass proportional to n. You might be tempted to think this is O(n^2) because there are two loops, but they run sequentially rather than nested, so their costs add rather than multiply, giving O(n) + O(n) = O(n). Each loop only touches each index once and does constant-time work per index, so there is no hidden nested iteration. For space, the candies list itself takes O(n) memory since it stores one integer per rating, and no other data structures grow with input size. Someone might guess O(1) space thinking only a few variables are used, but that overlooks the array allocated at the start that scales directly with the input length.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def candy(ratings: list[int]) -> int:
    candies = [1 for _ in range(len(ratings))]
    for i in range(1, len(ratings)):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1

    for i in reversed(range(1, len(ratings))):
        if ratings[i - 1] > ratings[i] and candies[i - 1] <= candies[i]:
            candies[i - 1] = candies[i] + 1

    return sum(candies)
```

### C++

```cpp
int candy(std::vector<int>& ratings) {
    std::vector<int> candies(ratings.size(), 1);
    for (size_t i = 1; i < ratings.size(); ++i) {
        if (ratings[i] > ratings[i - 1]) {
            candies[i] = candies[i - 1] + 1;
        }
    }
    for (int i = (int)ratings.size() - 2; i >= 0; --i) {
        if (ratings[i] > ratings[i + 1] && candies[i] <= candies[i + 1]) {
            candies[i] = candies[i + 1] + 1;
        }
    }
    return std::accumulate(candies.cbegin(), candies.cend(), 0);
}
```

### Rust

```rust
fn candy(ratings: &[i32]) -> i32 {
    let n = ratings.len();
    let mut candies = vec![1; n];
    for i in 1..n {
        if ratings[i] > ratings[i - 1] {
            candies[i] = candies[i - 1] + 1;
        }
    }
    for i in (0..n.saturating_sub(1)).rev() {
        if ratings[i] > ratings[i + 1] && candies[i] <= candies[i + 1] {
            candies[i] = candies[i + 1] + 1;
        }
    }
    candies.iter().sum()
}
```
