# 4Sum II

**Puzzle date:** 2026-10-26  
**Category:** hash map  
**Time complexity:** `O(n²)`  
**Space complexity:** `O(n²)`

## Explanation

The Counter is built from a doubly nested generator over a and b, which produces n × n pair sums, so building it costs O(n²). The return statement runs a second doubly nested generator over c and d, another n × n iterations, each doing one constant-time dictionary lookup. Two quadratic passes still total O(n²). The natural wrong answer is O(n³) or O(n⁴) by assuming all four arrays must be nested together — the whole point of the hash map is that it collapses four nested loops into two independent pairs. Space is also O(n²) because ab_sum stores one entry per distinct pair sum, and there can be up to n² distinct sums.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def four_sum_count(a: list[int], b: list[int], c: list[int], d: list[int]) -> int:
    ab_sum = Counter(x + y for x in a for y in b)
    return sum(ab_sum[-x - y] for x in c for y in d)
```

### C++

```cpp
int fourSumCount(std::vector<int>& a, std::vector<int>& b, std::vector<int>& c, std::vector<int>& d) {
    std::unordered_map<int, int> abSum;
    for (int x : a) {
        for (int y : b) {
            ++abSum[x + y];
        }
    }
    int result = 0;
    for (int x : c) {
        for (int y : d) {
            auto it = abSum.find(-x - y);
            if (it != abSum.end()) {
                result += it->second;
            }
        }
    }
    return result;
}
```

### Rust

```rust
fn four_sum_count(a: &[i32], b: &[i32], c: &[i32], d: &[i32]) -> i32 {
    let mut ab_sum: HashMap<i32, i32> = HashMap::new();
    for &x in a {
        for &y in b {
            *ab_sum.entry(x + y).or_insert(0) += 1;
        }
    }
    let mut result = 0;
    for &x in c {
        for &y in d {
            if let Some(&count) = ab_sum.get(&(-x - y)) {
                result += count;
            }
        }
    }
    result
}
```
