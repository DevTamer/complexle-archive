# Subsets

**Puzzle date:** 2026-06-27  
**Category:** backtracking  
**Time complexity:** `O(n * 2^n)`  
**Space complexity:** `O(n * 2^n)`

## Explanation

The dominant cost is the backtracking recursion, which explores every possible subset of the input list. For n elements, there are exactly 2^n subsets, and for each subset the code does a path[:] copy that can take up to O(n) time, giving you O(n * 2^n) total time. The space complexity is also O(n * 2^n) because the result list stores all 2^n subsets and each subset can have up to n elements. You might be tempted to say O(2^n) for time, but that misses the O(n) cost of copying each path into the result at every node of the recursion tree. The recursion stack itself only goes n levels deep, so it contributes just O(n) auxiliary space, which is dominated by the output storage.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def subsets(nums: list[int]) -> list[list[int]]:
    result = []
    def backtrack(start: int, path: list[int]):
        result.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()
    backtrack(0, [])
    return result
```

### C++

```cpp
void backtrack(std::vector<int>& nums, int start,
               std::vector<int>& path, std::vector<std::vector<int>>& result) {
    result.push_back(path);
    for (size_t i = start; i < nums.size(); i++) {
        path.push_back(nums[i]);
        backtrack(nums, i + 1, path, result);
        path.pop_back();
    }
}

std::vector<std::vector<int>> subsets(std::vector<int>& nums) {
    std::vector<std::vector<int>> result;
    std::vector<int> path;
    backtrack(nums, 0, path, result);
    return result;
}
```

### Rust

```rust
fn backtrack(nums: &[i32], start: usize,
             path: &mut Vec<i32>, out: &mut Vec<Vec<i32>>) {
    out.push(path.clone());
    for i in start..nums.len() {
        path.push(nums[i]);
        backtrack(nums, i + 1, path, out);
        path.pop();
    }
}

fn subsets(nums: &[i32]) -> Vec<Vec<i32>> {
    let mut out = Vec::new();
    backtrack(nums, 0, &mut Vec::new(), &mut out);
    out
}
```
