# Two Sum

**Puzzle date:** 2026-06-01  
**Category:** hash map  
**Time complexity:** `O(n)`  
**Space complexity:** `O(n)`

## Explanation

The algorithm iterates through the list exactly once, performing O(1) hash map lookups and insertions at each step, yielding O(n) time complexity overall. The hash map 'seen' stores at most n key-value pairs in the worst case (when no solution is found until the last element), resulting in O(n) space complexity.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def two_sum(nums: list[int], target: int) -> list[int]:
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target - n], i]
        seen[n] = i
    return []
```

### C++

```cpp
#include <vector>
#include <unordered_map>

std::vector<int> twoSum(std::vector<int>& nums, int target) {
    std::unordered_map<int, int> seen;
    for (int i = 0; i < nums.size(); i++) {
        int diff = target - nums[i];
        if (seen.count(diff))
            return {seen[diff], i};
        seen[nums[i]] = i;
    }
    return {};
}
```

### Rust

```rust
use std::collections::HashMap;

fn two_sum(nums: &[i32], target: i32) -> Vec<usize> {
    let mut seen = HashMap::new();
    for (i, &n) in nums.iter().enumerate() {
        if let Some(&j) = seen.get(&(target - n)) {
            return vec![j, i];
        }
        seen.insert(n, i);
    }
    vec![]
}
```
