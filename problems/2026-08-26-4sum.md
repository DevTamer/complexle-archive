# 4Sum

**Puzzle date:** 2026-08-26  
**Category:** arrays  
**Time complexity:** `O(n^3)`  
**Space complexity:** `O(n)`

## Explanation

The dominant cost comes from the nested structure: the outer two loops over i and j give O(n^2) pairs, and for each pair the inner while loop with left/right pointers scans the remaining array in O(n) time, giving O(n^3) overall. The sort at the start only costs O(n log n), which is dominated by the triple-nested scanning. A tempting wrong answer is O(n^2), which would be true if the two-pointer inner loop were O(1), but it actually scans up to n elements for every (i, j) pair, so you need that extra factor of n. Space is O(n) because sort typically uses O(log n) to O(n) auxiliary space depending on implementation, and the result list can grow with output, but the algorithm itself doesn't use extra data structures scaling faster than linear in the input size, aside from output storage which is not counted as auxiliary space in the standard analysis.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def four_sum(nums: list[int], target: int) -> list[list[int]]:
    nums.sort()
    n = len(nums)
    result = []
    for i in range(n - 3):
        if i and nums[i] == nums[i - 1]:
            continue
        for j in range(i + 1, n - 2):
            if j != i + 1 and nums[j] == nums[j - 1]:
                continue
            total = target - nums[i] - nums[j]
            left, right = j + 1, n - 1
            while left < right:
                if nums[left] + nums[right] == total:
                    result.append([nums[i], nums[j], nums[left], nums[right]])
                    left += 1
                    right -= 1
                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1
                elif nums[left] + nums[right] > total:
                    right -= 1
                else:
                    left += 1
    return result
```

### C++

```cpp
#include <vector>
#include <algorithm>

std::vector<std::vector<int>> fourSum(std::vector<int>& nums, int target) {
    std::sort(nums.begin(), nums.end());
    int n = (int)nums.size();
    std::vector<std::vector<int>> result;
    for (int i = 0; i + 3 < n; i++) {
        if (i && nums[i] == nums[i - 1]) continue;
        for (int j = i + 1; j + 2 < n; j++) {
            if (j != i + 1 && nums[j] == nums[j - 1]) continue;
            long long total = (long long)target - nums[i] - nums[j];
            int left = j + 1, right = n - 1;
            while (left < right) {
                long long sum = (long long)nums[left] + nums[right];
                if (sum == total) {
                    result.push_back({nums[i], nums[j], nums[left], nums[right]});
                    left++;
                    right--;
                    while (left < right && nums[left] == nums[left - 1]) left++;
                    while (left < right && nums[right] == nums[right + 1]) right--;
                } else if (sum > total) {
                    right--;
                } else {
                    left++;
                }
            }
        }
    }
    return result;
}
```

### Rust

```rust
fn four_sum(nums: &[i32], target: i32) -> Vec<Vec<i32>> {
    let mut nums = nums.to_vec();
    nums.sort();
    let n = nums.len();
    let mut result = Vec::new();
    if n < 4 {
        return result;
    }
    for i in 0..n - 3 {
        if i > 0 && nums[i] == nums[i - 1] {
            continue;
        }
        for j in i + 1..n - 2 {
            if j != i + 1 && nums[j] == nums[j - 1] {
                continue;
            }
            let total = target as i64 - nums[i] as i64 - nums[j] as i64;
            let mut left = j + 1;
            let mut right = n - 1;
            while left < right {
                let sum = nums[left] as i64 + nums[right] as i64;
                if sum == total {
                    result.push(vec![nums[i], nums[j], nums[left], nums[right]]);
                    left += 1;
                    right -= 1;
                    while left < right && nums[left] == nums[left - 1] {
                        left += 1;
                    }
                    while left < right && nums[right] == nums[right + 1] {
                        right -= 1;
                    }
                } else if sum > total {
                    right -= 1;
                } else {
                    left += 1;
                }
            }
        }
    }
    result
}
```
