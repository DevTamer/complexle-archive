# Plus One

**Puzzle date:** 2026-08-30  
**Category:** arrays  
**Time complexity:** `O(n)`  
**Space complexity:** `O(1)`

## Explanation

The dominant cost here is the single reversed loop over the digits array, which in the worst case (all 9s, like [9,9,9]) runs through every element once before falling through to the append step. Since each iteration does constant work (a comparison and either a reset or increment), the total work scales linearly with the number of digits, giving you O(n) time. You might be tempted to say O(1) because many inputs return early on the first non-9 digit, but Big-O accounts for the worst case, not the best case. For space, the function modifies the digits list in place and only uses a few extra variables (the loop index), so it needs O(1) extra space regardless of input size; the possible append at the end grows the same list rather than allocating a separate new structure proportional to n.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def plus_one(digits: list[int]) -> list[int]:
    for i in reversed(range(len(digits))):
        if digits[i] == 9:
            digits[i] = 0
        else:
            digits[i] += 1
            return digits
    digits[0] = 1
    digits.append(0)
    return digits
```

### C++

```cpp
#include <vector>

std::vector<int> plusOne(std::vector<int>& digits) {
    for (int i = (int)digits.size() - 1; i >= 0; --i) {
        if (digits[i] == 9) {
            digits[i] = 0;
        } else {
            ++digits[i];
            return digits;
        }
    }
    digits[0] = 1;
    digits.emplace_back(0);
    return digits;
}
```

### Rust

```rust
fn plus_one(digits: &[i32]) -> Vec<i32> {
    let mut digits = digits.to_vec();
    for i in (0..digits.len()).rev() {
        if digits[i] == 9 {
            digits[i] = 0;
        } else {
            digits[i] += 1;
            return digits;
        }
    }
    digits[0] = 1;
    digits.push(0);
    digits
}
```
