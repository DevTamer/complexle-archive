# Min Stack

**Puzzle date:** 2026-06-26  
**Category:** stack  
**Time complexity:** `O(1)`  
**Space complexity:** `O(n)`

## Explanation

Every operation — push, pop, top, and get_min — performs a fixed number of steps regardless of how many elements are in the stack, so each is O(1) time. The key insight is that Python's list append and pop from the end are both O(1) amortized, and the comparisons done are simple constant-time checks. You might be tempted to say O(n) for time because there are two stacks being maintained, but maintaining two stacks still only does a constant amount of work per call — it never loops over elements. For space, across n push operations you could store up to n elements in both the main stack and the min_stack, giving O(n) total space usage proportional to the number of elements pushed.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)

    def pop(self) -> None:
        v = self.stack.pop()
        if v == self.min_stack[-1]:
            self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def get_min(self) -> int:
        return self.min_stack[-1]
```

### C++

```cpp
class MinStack {
    std::vector<int> stack, minStack;
public:
    void push(int val) {
        stack.push_back(val);
        if (minStack.empty() || val <= minStack.back())
            minStack.push_back(val);
    }
    void pop() {
        if (stack.back() == minStack.back()) minStack.pop_back();
        stack.pop_back();
    }
    int top() { return stack.back(); }
    int getMin() { return minStack.back(); }
};
```

### Rust

```rust
struct MinStack {
    stack: Vec<i32>,
    min_stack: Vec<i32>,
}

impl MinStack {
    fn new() -> Self { Self { stack: vec![], min_stack: vec![] } }

    fn push(&mut self, val: i32) {
        self.stack.push(val);
        if self.min_stack.last().map_or(true, |&m| val <= m) {
            self.min_stack.push(val);
        }
    }

    fn pop(&mut self) {
        if let Some(v) = self.stack.pop() {
            if Some(&v) == self.min_stack.last() {
                self.min_stack.pop();
            }
        }
    }

    fn top(&self) -> i32 { *self.stack.last().unwrap() }
    fn get_min(&self) -> i32 { *self.min_stack.last().unwrap() }
}
```
