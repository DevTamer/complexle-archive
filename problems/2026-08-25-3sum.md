# 3Sum

**Puzzle date:** 2026-08-25  
**Category:** arrays  
**Time complexity:** `O(n^2)`  
**Space complexity:** `O(n)`

## Explanation

The dominant cost comes from the outer loop over each index i combined with the inner two-pointer while loop scanning left and right across the remaining array. Even though sorting takes O(n log n), the outer loop runs O(n) times and for each iteration the two-pointer scan does up to O(n) work, giving O(n^2) overall, which dominates the sort. A tempting wrong answer is O(n^3), which would apply if you used three nested loops instead of the two-pointer technique, but here the sorted array lets the inner two pointers replace the third loop. For space, the sort itself (or the result list construction) uses O(n) auxiliary space beyond the output, not counting the result list which is considered output storage.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def three_sum(nums: list[int]) -> list[list[int]]:
    result = []
    nums = sorted(nums)
    n = len(nums)
    for i in range(n - 1, 1, -1):
        if i + 1 < n and nums[i] == nums[i + 1]:
            continue
        target = -nums[i]
        left, right = 0, i - 1
        while left < right:
            if nums[left] + nums[right] < target:
                left += 1
            elif nums[left] + nums[right] > target:
                right -= 1
            else:
                result.append([nums[left], nums[right], nums[i]])
                left += 1
                right -= 1
                while left < right and nums[left] == nums[left - 1]:
                    left += 1
                while left < right and nums[right] == nums[right + 1]:
                    right -= 1
    return result
```

### C++

```cpp
std::vector<std::vector<int>> threeSum(std::vector<int>& nums) {
    std::sort(nums.begin(), nums.end());
    std::vector<std::vector<int>> result;
    int n = static_cast<int>(nums.size());
    for (int i = n - 1; i >= 2; --i) {
        if (i + 1 < n && nums[i] == nums[i + 1]) {
            continue;
        }
        int target = -nums[i];
        int left = 0, right = i - 1;
        while (left < right) {
            if (nums[left] + nums[right] < target) {
                ++left;
            } else if (nums[left] + nums[right] > target) {
                --right;
            } else {
                result.push_back({nums[left], nums[right], nums[i]});
                ++left; --right;
                while (left < right && nums[left] == nums[left - 1]) {
                    ++left;
                }
                while (left < right && nums[right] == nums[right + 1]) {
                    --right;
                }
            }
        }
    }
    return result;
}
```

### Rust

```rust
fn three_sum(nums: &[i32]) -> Vec<Vec<i32>> {
    let mut nums = nums.to_vec();
    nums.sort();
    let n = nums.len();
    let mut result = Vec::new();
    let mut i: i32 = n as i32 - 1;
    while i >= 2 {
        let iu = i as usize;
        if iu + 1 < n && nums[iu] == nums[iu + 1] {
            i -= 1;
            continue;
        }
        let target = -nums[iu];
        let mut left: i32 = 0;
        let mut right: i32 = i - 1;
        while left < right {
            let l = left as usize;
            let r = right as usize;
            if nums[l] + nums[r] < target {
                left += 1;
            } else if nums[l] + nums[r] > target {
                right -= 1;
            } else {
                result.push(vec![nums[l], nums[r], nums[iu]]);
                left += 1;
                right -= 1;
                while left < right && nums[left as usize] == nums[(left - 1) as usize] {
                    left += 1;
                }
                while left < right && nums[right as usize] == nums[(right + 1) as usize] {
                    right -= 1;
                }
            }
        }
        i -= 1;
    }
    result
}
```
