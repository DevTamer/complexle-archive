# H-Index

**Puzzle date:** 2026-10-02  
**Category:** arrays  
**Time complexity:** `O(n)`  
**Space complexity:** `O(n)`

## Explanation

You first loop through all n citations once to fill the count array, then loop through the count array (of size n+1) once more to find the h-index, so the dominant cost is two sequential linear passes over data of size n. Since both loops scale directly with n and there's no nested iteration or sorting involved, the total work is O(n). A tempting wrong answer is O(n log n), which people often guess because the classic h-index solution sorts the citations first, but this bucket-counting approach avoids sorting entirely by using counting sort logic instead. The space complexity is O(n) because you allocate a new list 'count' of size n+1, which grows linearly with the input size regardless of the values in citations.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def h_index(citations: list[int]) -> int:
    n = len(citations)
    count = [0] * (n + 1)
    for x in citations:
        # Put all x >= n in the same bucket.
        if x >= n:
            count[n] += 1
        else:
            count[x] += 1

    h = 0
    for i in reversed(range(n + 1)):
        h += count[i]
        if h >= i:
            return i
    return h
```

### C++

```cpp
int hIndex(std::vector<int>& citations) {
    int n = static_cast<int>(citations.size());
    std::vector<int> count(n + 1, 0);
    for (int x : citations) {
        // Put all x >= n in the same bucket.
        if (x >= n) {
            count[n]++;
        } else {
            count[x]++;
        }
    }

    int h = 0;
    for (int i = n; i >= 0; i--) {
        h += count[i];
        if (h >= i) {
            return i;
        }
    }
    return h;
}
```

### Rust

```rust
fn h_index(citations: &[i32]) -> i32 {
    let n = citations.len() as i32;
    let mut count = vec![0; (n + 1) as usize];
    for &x in citations {
        // Put all x >= n in the same bucket.
        if x >= n {
            count[n as usize] += 1;
        } else {
            count[x as usize] += 1;
        }
    }

    let mut h = 0;
    for i in (0..=n).rev() {
        h += count[i as usize];
        if h >= i {
            return i;
        }
    }
    h
}
```
