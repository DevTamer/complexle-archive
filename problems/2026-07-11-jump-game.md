# Jump Game

**Puzzle date:** 2026-07-11  
**Category:** arrays  
**Time complexity:** `O(n)`  
**Space complexity:** `O(1)`

## Explanation

The dominant cost is the single for-loop that iterates over every element in the nums list exactly once. Each iteration does only constant-time work: a comparison, a max call, and an update to the 'reachable' variable. You might be tempted to think this is O(n²) because of the max() call inside the loop, but max() here compares exactly two values, making it O(1) per iteration. The only extra memory used is the single integer variable 'reachable', which does not grow with input size, giving O(1) space.

## Implementations

All three implement the same algorithm, so they share the same time and
space complexity — only the language differs.

### Python

```python
def can_jump(nums: list[int]) -> bool:
    reachable = 0
    for i, n in enumerate(nums):
        if i > reachable:
            return False
        reachable = max(reachable, i + n)
    return True
```

### C++

```cpp
#include <vector>
#include <algorithm>

bool canJump(std::vector<int>& nums) {
    int reachable = 0;
    for (int i = 0; i < (int)nums.size(); i++) {
        if (i > reachable) return false;
        reachable = std::max(reachable, i + nums[i]);
    }
    return true;
}
```

### Rust

```rust
fn can_jump(nums: &[i32]) -> bool {
    let mut reachable = 0i32;
    for (i, &n) in nums.iter().enumerate() {
        if i as i32 > reachable {
            return false;
        }
        reachable = reachable.max(i as i32 + n);
    }
    true
}
```
